# 06 — Engineering, Projects, SolarCare & Warranty

## Engineering Capability

This is a major differentiating page.

Present as an **interactive engineering journey / timeline** rather than a conventional list.

### Pre-Construction
Feasibility → Shadow Analysis → 3D Layout → PVsyst → DPR → Financial Modelling → Risk Review

### Execution
Engineering → Procurement → Installation → Commissioning → Performance Assurance

### Quality
Tier-1 Components → QA → Testing → Documentation → Traceability

Keep the experience visual, progressive and premium.
