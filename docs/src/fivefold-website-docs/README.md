## Purpose of this package

This documentation package defines a **clean, interactive and minimal** website experience for Fivefold Renewable.

The goal is to move from a conventional informational solar website to a focused **Solar Decision Platform** that:

- Communicates engineering-led expertise
- Makes it easy for visitors to estimate requirements
- Discovers applicable government schemes
- Explores residential, commercial and industrial solutions
- Views projects & credentials
- Understands SolarCare AMC and warranty support
- Submits qualified enquiries
