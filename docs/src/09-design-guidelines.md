# 09 — Design Guidelines (Clean · Interactive · Minimal)

## Overall Aesthetic

- Premium engineering feel
- Calm, trustworthy, modern
- Generous whitespace
- Clear visual hierarchy
- One primary action per screen

## Colour & Typography Direction

- Primary: Deep engineering blues + clean neutrals
- Accent: Used sparingly for CTAs and interactive highlights
- Typography: Clean sans-serif, excellent readability on mobile and desktop
- Avoid bright, salesy colours or overly decorative fonts

## Layout Principles

- Card-based UI for solutions, projects, AMC plans and scheme results
- Progressive disclosure (reveal complexity only when needed)
- Consistent spacing system
- Mobile-first responsive behaviour
- Fast loading — lightweight motion only

## Motion Guidelines

- Lightweight transitions and progressive reveals are welcome
- Avoid heavy parallax, continuous animations or motion that impacts performance
- Signature interactions (calculator results, scheme finder, engineering timeline) may use purposeful motion
- Everything else should remain still unless motion improves clarity

## Content Tone

- Engineering-led, not salesy
- Short paragraphs and scannable lists
- Clear disclaimers on estimates, subsidies and savings claims
- Confident but never exaggerated

## Accessibility & Performance

- Semantic HTML and accessible form controls
- Sufficient colour contrast
- Keyboard navigable interactive elements
- Optimised images and minimal third-party scripts
- Target excellent Core Web Vitals

## Consistency Rules

- Same card language across Solutions, Projects, Schemes and SolarCare
- Same primary CTA style site-wide
- Same disclaimer treatment for any estimate or government-related claim
- Header and footer remain consistent on every page

These guidelines ensure the finished website stays clean, interactive and minimal while still delivering strong conversion performance.
